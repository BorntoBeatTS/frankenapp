# FrankenApp

FrankenApp is a darkly humorous SaaS landing page and interactive Mutation Lab. Founders can bolt feature organs onto an app creature and watch its complexity mutate.

## Included

- React + Vite landing page
- Interactive Mutation Lab
- DNA intake and specimen generation
- Feature organ selection and grafting
- Ambient audio and mutation video overlays
- Responsive layout

## Run locally

Requirements: Node.js and pnpm.

```bash
pnpm install
pnpm --filter @workspace/frankenapp run dev
```

The app is a frontend-only experience and does not require a backend.
